# Python-Basics-Week1
This repository contains my first two Python terminal applications built during my first week of learning Python.

## Projects Included
1. **Calculator App:** Uses modern `match/case` logic to handle addition, subtraction, multiplication, and division.
2. **Todo App:** A clean, terminal-based task manager using Python lists and input loops.

## What I Learned
* Dynamic loops (`while True`)
* Data handling with Python Lists
* Reusable logic using functions
* Dynamic index offsetting (`enumerate`)
